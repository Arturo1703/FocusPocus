# Focus Pocus

Aplicación Android personal de concentración y bloqueo de distracciones.

## Estado

Proyecto en desarrollo. Actualmente incluye:

- Interfaz con Jetpack Compose y Material 3.
- Navegación principal con Navigation 3.
- Secciones Blocking, Focus, Perfiles, Estadísticas y Ajustes.
- Selección de aplicaciones con vídeos cortos.
- Primer prototipo de detección de YouTube Shorts mediante accesibilidad.

## Tecnología

- Kotlin
- Jetpack Compose
- Material 3
- Navigation 3
- Minimum SDK 26

El bloqueo real y las demás plataformas se incorporarán progresivamente.
